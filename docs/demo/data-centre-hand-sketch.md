# Data Centre whiteboard demo

Sign in and open **Whiteboard → Sample whiteboards → Data Centre — Hand Sketch → Use sample**. EasyDraw creates a private editable copy and prefills **Describe your idea** with the prompt below. Choose **Generate preview**, review the result in 2D and 3D, and choose **Create diagram** to save an editable copy. The built-in sample remains available to every account.

**The sample's preview is built in, not generated.** The copy carries `sample: "data-centre-whiteboard"` in its whiteboard document, so Generate preview answers at once with the dashboard's Data Centre diagram (`createDataCentreDocument()`, 3D equipment included) and Create diagram saves that same diagram through the ordinary `POST /diagrams` API. No request reaches the preview API, S3 or OpenAI, nothing is charged, and the result is the same after a reload or a repaint. The prompt is shown read-only for reference; refinement is not offered because there is nothing to refine. See `client/src/lib/whiteboard/preview/built-in-preview.ts`.

The standalone [PNG sketch](data-centre-hand-sketch.png) can also be opened with **File → Open image…** on an ordinary Whiteboard. That path is real AI recognition: paste the prompt yourself, expect an approximate result, and expect an OpenAI charge.

```text
Turn this top-view hand sketch into a clean, editable data-centre floor-plan diagram in English. Keep the three zones and their positions: Compute Hall on the left, Infrastructure on the right, and Network Operations Centre across the bottom. In Compute Hall, show three CRAC cooling units, two separate rows of five server racks labelled A-01 to A-05 and B-01 to B-05, and a cold aisle between the rows marked 18–22°C. In Infrastructure, show UPS A, UPS B, PDU, Spine A, Spine B, and SAN 01 to SAN 03. Connect Spine A to each Row A rack with teal Fabric A cables. Connect Spine B to each Row B rack and all three SAN units with blue Fabric B cables. In the operations centre, show Access, Monitoring, Network and Security. Use separate editable shapes and text for every device and real connector edges for the cables. Preserve the floor-plan layout and labels; make it neat and easy to present. Do not add devices, direction arrows on the physical cables, or a generic software flowchart.
```

The sketch is a simplified teaching/demo input derived from the structure of the dashboard Data Centre sample. On the manual AI path the 3D preview can give recognised shapes depth, but the prompt does not install the sample's bespoke 3D equipment recipes; only the built-in sample result and the dashboard sample carry them.
